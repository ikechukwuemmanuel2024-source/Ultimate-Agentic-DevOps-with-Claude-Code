Reflection – Week 2
By: Ikechukwu Emmanuel
1. Biggest Technical Insight I Got This Week
Week 2 completely changed the way I think about AI in software development. Before this week, I saw AI mainly as a tool for answering questions or generating code. After working with Claude Code throughout the DevOps Micro Internship, I realised that Agentic AI can become an active part of a structured engineering workflow.
One of the biggest concepts I learned was how CLAUDE.md helps define project rules and keeps Claude consistent across tasks. I also learned how Skills turn long prompts into reusable slash commands, making repetitive tasks much faster. Working with Hooks and Permissions also showed me how important it is to balance automation with safety by controlling what AI is allowed to do.
2. Biggest Insight I Got About Myself This Week
This week helped me understand my learning style better. I realised that I learn much more effectively by building and troubleshooting than by simply watching tutorials. Every time I encountered an error, fixing it taught me something I probably wouldn't have learned otherwise.
I also discovered that persistence is one of my strengths. There were several assignments where I became frustrated because something refused to work, but I kept trying until I finally understood the problem and solved it.
3. My Biggest Weakness or Loop I Noticed
The biggest weakness I noticed is that I sometimes move too quickly without carefully checking every instruction. More than once, I had to repeat tasks because I missed a small detail such as working in the wrong project folder, using an incorrect file path, or forgetting a required screenshot.
I also noticed that when I see an error message, I sometimes assume the problem is complicated when it is actually something simple. Reading error messages carefully usually points me in the right direction.
4. One System I Will Implement From This Week
Going forward, I will create a checklist before starting every assignment.
Before writing any code or running commands, I will:
Read the prerequisites completely.
List every required screenshot.
Verify that I am inside the correct project folder.
Tick off each task before moving to the next one.
This habit will help me stay organised, avoid repeating work, and complete assignments more efficiently.
5. What I Learned About Agentic AI and DevOps
This week changed my understanding of both DevOps and AI. I learned that Agentic AI is much more than a chatbot—it can follow structured workflows, remember project context, use specialised skills, and interact with development tools.
I also realised that automation alone is not enough. Features like Hooks, Permissions, and Memory showed me that engineers still need to review outputs, configure safety rules, and understand what the AI is doing. DevOps is about building reliable systems, and that includes using AI responsibly.
6. My Week 2 Highlight
The highlight of my week was successfully configuring Claude Code features such as Memory, Hooks, and Permissions after spending time troubleshooting different issues. Although some tasks took much longer than I expected, solving those problems gave me more confidence in using the terminal, understanding project structure, and working with AI-powered development tools.
Looking back, Week 2 was challenging, but it also helped me grow as a learner. I became more comfortable with debugging, following documentation carefully, and using Agentic AI as a practical engineering tool rather than just an assistant. I know there is still a lot to learn, but I can already see how these skills will help me as I continue my journey towards becoming a Cloud and DevOps Engineer.
