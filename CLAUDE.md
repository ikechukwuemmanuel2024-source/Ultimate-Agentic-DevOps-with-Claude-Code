# CLAUDE.md

## Project Overview

This project is a static website used for learning Agentic AI with Claude Code as part of the DevOps Micro Internship (DMI). The repository contains HTML, CSS, images, and supporting documentation used to demonstrate Claude Code workflows.

---

## Architecture

The project consists of:

- HTML pages (`index.html`, `privacy.html`, `terms.html`)
- CSS styling (`style.css`)
- Image assets stored in the `images/` directory
- Documentation in `README.md`
- Claude Code configuration through `CLAUDE.md`

---

## Build Workflow

This project does not require a build process.

Any changes made to the HTML, CSS, or image files are reflected directly when the website is opened in a browser.

---

## Deployment Workflow

The website can be deployed using GitHub Pages or any static web hosting service.

Deployment steps:

1. Make the required changes.
2. Commit the changes using Git.
3. Push the changes to GitHub.
4. Verify the website after deployment.

---

## Coding Guidelines

- Keep HTML clean and properly indented.
- Use meaningful file names.
- Maintain consistent CSS formatting.
- Do not delete existing project files unless instructed.
- Follow the existing project structure.
- Prefer minimal and readable changes.
